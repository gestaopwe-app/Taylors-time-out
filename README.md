# Taylors Time Out

App interna do stand: abrir e fechar turno, avisos de falta, movimentos de caixa,
mercadoria recebida, pedidos, escala e gestão. Exporta os mapas mensais em Excel.

Entrada por código pessoal. Este repositório não contém dados nem códigos:
tudo fica na base de dados (Supabase), protegida no servidor.
